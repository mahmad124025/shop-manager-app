# Shop Manager App

A professional Flutter-based shop management application for small businesses — handles inventory, sales, customers, suppliers, and financial reporting with cloud sync and secure access.

## Features
- Inventory management with barcode scanning
- Sales/billing with sale history tracking
- Customer and supplier management
- Expense tracking and monthly cycle reports
- Annual and item-wise sales reports
- PDF invoice/report generation and sharing
- WhatsApp integration for sharing invoices and reports
- Firebase Authentication and Firestore cloud sync
- PIN lock and biometric authentication for security
- In-app calculator overlay
- Local notifications
- Custom splash screen and branding

## Technologies
- Flutter & Dart
- Firebase (Authentication, Firestore)
- SQLite (local database)
- PDF generation & printing
- Biometric/local authentication
- Barcode scanning

## How to Run
1. Clone the repository
2. Run `flutter pub get`
3. Set up Firebase project and add `google-services.json` to `android/app/`
4. Run `flutter run`
